Define Software Engineering:

What is software engineering, and how does it differ from traditional programming?

Software engineering is the branch of computer science that deals with the design, development, testing, and maintenance of software applications.

How does it differ from traditional programming?
software engineering aims to create reliable, efficient, and scalable software systems that meet specified requirements while traditional programming does not.
software engineering emphasizes comprehensive documentation while traditional programming is less comprehensive and less formal.

Requirements Engineering:

What is requirements engineering? Describe the process and its importance in the software development lifecycle.
It is a phase in the software development process that involves the systematic process of defining, documenting, and maintaining the requirements for a software system. 

Proccess of requirements engineering
Requirements Elicitation-Information about the desired functions, features, and constraints of the software system from stakeholders are gathered through interviews,Surveys and Questionnaires and Workshops and Focus Groups.
Requirements Analysis and Negotiation-The objective is to analyze, refine, and prioritize the gathered requirements to ensure they are clear, complete, and feasible.
Requirements Documentation-Requirements are documented in a clear, structured, and accessible format.
Requirements Validation-Ensures stakeholders needs and requirements are meet.
Requirements Management-Managing changes to the requirements and maintain their consistency and traceability throughout the project lifecycle.

Software Maintenance:

Define software maintenance and explain the different types of maintenance activities. Why is maintenance an essential part of the software lifecycle?
Software maintenance involves modifying and updating software after it has been deployed.It enhance the system's functionality.

types of maintenance activities

Corrective maintenance
Fixes defects or bugs discovered in the software.
It ensures the software remains functional and reliable by correcting faults that could disrupt operations.
Adaptive maintenance
Purposes to adapt the software to changes in its environment or external systems
Keeps the software compatible with evolving technical environments and regulatory landscapes.
Perfective maintenance
Improves the software’s performance.
It enhances user satisfaction.
Preventive maintenance:
Identifies and fixes faults before they become actual issues.
It reduces the risk of future problems.

Why is maintenance an essential part of the software lifecycle?
To ensures that the software continues to meet user requirements over time. 
Cost efficiency as bugs are fixed at an early stage.
Performance optimization and reliability
Enhanced security.
User satisfaction through feedback.
